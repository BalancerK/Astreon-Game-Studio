Platformer (tutorial game)

A small 2D platformer: three levels, running and jumping with coyote time, jump buffering and variable height, walking enemies you can stomp, springs, spikes, coins, sound made in code, and best times kept in the browser. Walkthrough: docs/tutorials/2d-platformer.md.

npm run platformer      # then open the printed address

Arrows or A/D run, Space / W / Up jump, R restarts the level, N goes to the next, Esc shows the level list. A gamepad works too.

FileWhat it is
src/level.jsReads levels written as rows of letters; merges ground tiles into boxes
src/game.jsThe rules: createGame, step(game, bits), replay, botInput. No screen, no clock
src/main.jsThe page: drawing, input, sound, saved times
levels/*.jsonThe levels (add a file and list it in levels/index.json)
test/game.test.jsThe rules, every level finished by a bot, replays

Tests: npm test runs test/game.test.js; node tools/platformer-test.js plays a level in Chrome with real key presses on both renderers.

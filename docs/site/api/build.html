@engine/build

Production build (bundle, minify, content-hashed files, manifest, precompression) and a dev server with live manifest and page reload.

npm install @engine/build

Version 0.1.0. The package's own README (packages/build) explains how the pieces fit together; this page lists every export.

Command line: engine-build

async function checkBundle(entry, { root, alias, define, minify = false, only = () => true, load = (file) => import(pathToFileURL(file).href) } = {})

Load every module of a bundle both through the bundle and as the real module in Node, and compare the names each exports and what they are. Modules run twice (once each way), so give only to leave out the ones that touch the page.

serve#

async function serve({ root = '.', assets = [], port = 8080, host = '127.0.0.1', liveReload = true, writable = [], handle, log = () => {} } = {})

handle(req, res) runs first for every request: return true if it answered (your own API next to the pages). writable lets pages (the scene editor) list, read, write and delete files in chosen folders: [{ route: '/__scenes', dir: 'scenes', ext: '.json' }]. Names are checked, only that extension is touched, bodies are capped, JSON is validated, writes are atomic, and requests from other origins are refused.

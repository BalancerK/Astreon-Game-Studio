@engine/prefab

Entity templates as JSON: inheritance, children, parameters, overrides, parent-child transforms, capturing what changed for saves.

npm install @engine/prefab

Version 0.1.0. The package's own README (packages/prefab) explains how the pieces fit together; this page lists every export.

PrefabLibrary.resolve#

resolve(name, stack = [])

The prefab with everything it inherits merged in: bases first (extends may be a name or a list), then its own values on top. Components and extras merge field by field; tags are united; children merge by name (a child of the same name changes the inherited one, a new name adds one); params merge by name. The result is a new object you may keep.

Returns any

PrefabLibrary.validate#

Check every prefab against the registry: components and fields exist, values can be numbers, child prefabs exist, no circles, parameters point at something. Throws an error listing every problem found.

Makes entities from prefabs and takes them apart again. spawn(name, { at, params, overrides, parent, local, id }) returns an Instance; extra(key, handler) teaches it what the game's own data (physics bodies, meshes) means; capture(instance) gives just what changed since the spawn, for saves.

PrefabSpawner.extra#

extra(key, fn, { after = false } = {})

Teach the spawner what an extras key means: fn(value, { entity, instance, world, spec, path }) is called for every part that has it, after its components exist (or, with { after: true }, after its children have been made too). Return a function to be run when the instance is destroyed.

PrefabSpawner.capture#

capture(instance)

What differs now from what the prefab says, as overrides: spawn the prefab again with these and you get the same thing back. Includes changed component values (relative to the prefab's own, not counting this instance's parameters and overrides), components added or removed since, changed tags, children's local poses, and children that were destroyed. Extras are not captured: they are the game's own business.

Returns {prefab: string, overrides: Record<string, any>}

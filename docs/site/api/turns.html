@engine/turns

Turn-based and card games: rules as plain functions with hidden information and seeded randomness, a server room (tokens, robots, turn timers, rematch) and a client with reconnect.

npm install @engine/turns

Version 0.1.0. The package's own README (packages/turns) explains how the pieces fit together; this page lists every export.

class TurnClient#

class TurnClient

The player's side of a turn-based game: connects to the room with a join token, keeps the latest view, current player and legal moves, sends moves (move() resolves when the room accepts it), and reconnects with a fresh token if the connection drops. It draws nothing: a page reads its fields and listens to onEvents.

class TurnRoom#

class TurnRoom

A running table: checks join tokens, seats the players, starts the match, applies moves with the game's own rules, sends each player only what they may see, plays for robots and for players who are away, enforces turn limits, offers a rematch, and reports each result through stats(). Normally created for you by turnRoom(game).

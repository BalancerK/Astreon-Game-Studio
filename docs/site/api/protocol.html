class SnapshotCodec#

class SnapshotCodec

Encodes/decodes snapshots as full state or as a delta against an acked baseline. Holds scratch buffers, so create one per schema and reuse it.

Delta layout (after a kind byte and tick): baseline tick, removed ids, then only entities that changed: slot-index gap, generation, presence mask, and per present component either all fields (new) or a changed-field mask followed by just those fields.

class SnapshotHistory#

class SnapshotHistory

Fixed ring of recent snapshots, looked up by tick. The server keeps one per client (or one shared) to find the acked baseline for deltas; the client keeps one to decode incoming deltas.

Usage: slot = h.acquire(), fill it (capture/decode), then h.commit(slot). A slot that was acquired but never committed (e.g. decode threw) is never returned by get, so a half-written snapshot can't become a baseline. Acquiring evicts the oldest entry, so size the ring larger than the longest ack lag you want to serve deltas for; beyond that, get returns undefined and the sender falls back to a full snapshot.

Codec#

A codec turns a number into a wire value and back. Values are held in "stored" form (quantized integer for q-codecs, the number itself otherwise), so change detection compares exact integers and never jitters.

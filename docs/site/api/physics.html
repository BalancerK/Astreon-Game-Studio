@engine/physics

2D spatial hash and swept box collision; 3D triangle worlds, swept-ellipsoid movement and a character controller (no tunnelling at any speed); rigid bodies with joints, sleeping and triggers.

npm install @engine/physics

Version 0.1.0. The package's own README (packages/physics) explains how the pieces fit together; this page lists every export.

findGround#

function findGround(world, x, y, z, rx, ry, rz, out)

Is the ellipsoid standing on something? Looks at every triangle it is touching (within about 1% of its radius) whose touch point is in the lower part of the body, and reports the most horizontal of their face normals (pointing up). Using the triangle's own normal rather than the ellipsoid's contact normal matters at ledges and stair edges: the body rests on an edge there, the contact direction is tilted, yet the surface it stands on is a flat tread.

moveEllipsoid#

function moveEllipsoid(world, px, py, pz, vx, vy, vz, rx, ry, rz, out, wallBelowY = 0, stopAtContact = false)

Move an ellipsoid (a character body) through static triangle geometry and slide along what it hits. The motion is a continuous sweep, so no speed can carry it through a surface (even a single zero-thickness triangle), and the result is the same bits on every engine. Works in "ellipsoid space": every coordinate divided by the radii makes the body a unit sphere, which is what the narrow phase sweeps.

Up to 5 contacts are processed; when the motion is jammed between two surfaces it slides along their crease, and between three it stops.

class Body2D#

class Body2D

A 2D simulated object: a circle or convex polygon with mass, friction, bounciness and damping, of type dynamic (simulated), kinematic (moved only by the velocity you give it, pushes others) or static (never moves). Coordinates are metres with +y down, like the 2D renderer; angles are in radians, positive turning clockwise on screen. The rotation is kept as a cosine and sine so the simulation never needs a trigonometric function.

class CharacterController#

class CharacterController

A first- or third-person character body: walks on slopes, climbs steps, falls, jumps, stands still without jitter and slides down surfaces that are too steep. Collision is an ellipsoid swept through a TriWorld, so nothing tunnels at any speed. One update is one tick: the same function runs on the server (authoritative) and in the client (prediction), and uses only + - * / and sqrt, so both get the same bits on every engine.

Coordinates: +y up. x, y, z is the centre of the body; the feet are at y - halfHeight.

class TriWorld

Static 3D collision geometry: a triangle soup indexed by a uniform 3D grid (typed arrays, built once).

@engine/debug

In-page overlay: live graphs and a decoded packet inspector (F3).

npm install @engine/debug

Version 0.1.0. The package's own README (packages/debug) explains how the pieces fit together; this page lists every export.

class DebugOverlay#

class DebugOverlay

In-page debug panel: live graphs for each series, info lines and a packet inspector. Toggle with F3 (or toggle()). Sampling always runs (cheap) so history is there when you open it; drawing only happens while it is visible.

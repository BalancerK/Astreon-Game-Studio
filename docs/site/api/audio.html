@engine/audio

Web Audio mixer with buses and a limiter, positional sound, voice limits, music cross-fades, and sounds made in code (no files needed).

npm install @engine/audio

Version 0.1.0. The package's own README (packages/audio) explains how the pieces fit together; this page lists every export.

dopplerRatio#

function dopplerRatio(listener, listenerVelocity, position, velocity, speedOfSound = 343, strength = 1)

Doppler shift: how much higher (above 1) or lower (below 1) a moving source sounds to a moving listener. A source coming at you, or you going at it, raises the pitch; going away lowers it. Only the speeds along the line between the two count. The result is held to 0.5..2 so a shout across a supersonic gap cannot make noise.

class AudioEngine#

class AudioEngine

Sound for games on the Web Audio API: a mixer of named buses (master, sfx, music, ui, voice, or your own), voice limiting with priorities, positional sound relative to a listener (distance fall-off and left/right panning), music with cross-fades, and sounds that can be made in code (see synth.js) so a game needs no audio files to start.

Browsers keep audio silent until the player has interacted with the page; the engine listens for the first click, key press or touch and starts then (unlockOnGesture). Until it is running, one-shot sounds are skipped (a burst of stale sounds would play the moment it unlocks) while looping music is kept waiting.

class JitterBuffer#

class JitterBuffer

Packets cross a network late, out of order, twice or not at all; speech has to come out at an even pace. The jitter buffer holds a few frames back (the delay), puts them in order, and on each tick of the playback clock (pull, once per frame) gives the next frame, or says one is missing so the player can cover the gap. The delay adapts: it grows when packets keep arriving too late to use and shrinks again when the network is steady. A burst of speech ends with an end packet, after which the buffer goes quiet until the next burst.

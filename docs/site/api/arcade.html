@engine/arcade

A small kit for a first game (the studio's pathway starts here): things as plain objects, easy key names, walking, jumping and walls, levels drawn with letters, boxes and emoji, a camera.

npm install @engine/arcade

Version 0.1.0. The package's own README (packages/arcade) explains how the pieces fit together; this page lists every export.

class Lockstep#

class Lockstep

The agreement between two (or more) computers about whose keys count on which tick.

Each tick: call local(keys) once with the keys this player holds now (it gives back the message to send); call receive(message) for every message from the others; and simulate a tick only if ready(), taking take() for the keys of every player. The keys held on tick t are used on tick t + delay, so the first delay ticks run with nobody holding anything. Messages may arrive late, twice, or out of order; they never need to arrive in any particular order.

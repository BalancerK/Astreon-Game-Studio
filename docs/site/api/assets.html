@engine/assets

Asset manager: one fetch per file, hashed-name manifest, use counting, retries, dependencies, hot reload.

npm install @engine/assets

Version 0.1.0. The package's own README (packages/assets) explains how the pieces fit together; this page lists every export.

class AssetManager#

class AssetManager

Loads, caches and reloads game files. Ask for an asset by type and logical path (load("image", "tex/bricks.png")); it finds the real (possibly content-hashed) URL in the manifest, fetches it once however many ask, decodes it with the loader for its type, counts who uses it, frees it with collect() when nobody does, and swaps in new versions when files change (update(manifest)).

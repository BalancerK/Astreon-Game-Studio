@engine/ui

Menus and HUDs on the 2D renderer: flexbox-style layout, buttons, sliders, switches, text fields, lists, themes, keyboard / gamepad / mouse / touch navigation, and ready-made pause, settings (key rebinding) and room-browser screens.

npm install @engine/ui

Version 0.1.0. The package's own README (packages/ui) explains how the pieces fit together; this page lists every export.

attachAccessibility#

function attachAccessibility(ui, { document: doc = globalThis.document, host = null, label = 'Game menu', field = null } = {})

Mirror the UI in the page for assistive technology. The canvas is invisible to a screen reader; this builds a hidden, always up to date set of real elements with the right ARIA roles (buttons, switches, sliders, text fields, lists, headings, dialogs) that it can read and operate: activating one clicks the widget, the arrow keys on a slider go through the same key handling as for everyone else, and moving the screen reader's cursor onto a control moves the UI's focus there. Announcements (ui.announce) go to live regions; opening a screen announces its name. Also sets ui.reducedMotion from the system's reduced-motion setting. Call the returned update() once a frame (it only touches what changed).

class Ui#

class Ui

Immediate-feeling, retained-mode UI: build a tree of widgets once, change their state when something happens, and call update(dt) and draw() every frame. Screens (menus, dialogs) stack on top of the game; a hud layer holds permanent widgets.

Input comes from pointerDown/Move/Up, wheel, key, text and the gamepad-style navigate / activate / cancel; every one returns whether the UI used it, so the game can ignore what the UI took. attachDom wires all this to a page.

class Widget#

class Widget

A node in the UI tree. Containers lay their children out (see layout.js); leaf widgets (label, button, ...) measure and draw themselves. Everything is in logical pixels; the Ui applies the scale.

Style (all optional):

  • direction: 'column' (default), 'row' or 'stack' (children overlap, placed by anchor).
  • gap, padding (number, [vertical, horizontal] or [top, right, bottom, left]).
  • align: cross axis, 'stretch' (default), 'start', 'center', 'end'. justify: main axis, 'start' (default), 'center', 'end', 'between'.
  • width / height: a number, or 'fill' (take the free space); grow: share of free space along the parent's main axis; minWidth, minHeight, maxWidth, maxHeight; alignSelf overrides the parent's align for this child.
  • anchor (children of a 'stack'): 'fill' (default), 'center', 'top', 'bottom', 'left', 'right', 'top-left', 'top-right', 'bottom-left', 'bottom-right'; offsetX, offsetY.
  • background, border: packed colours (or true for the theme's panel colours); radius.

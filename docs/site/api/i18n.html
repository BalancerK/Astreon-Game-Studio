@engine/i18n

Localisation: plural forms for every language, contexts, gettext .po and CSV import, fallback chains (pt-BR to pt), pseudo-localisation, a list of what is untranslated.

npm install @engine/i18n

Version 0.1.0. The package's own README (packages/i18n) explains how the pieces fit together; this page lists every export.

class Localizer#

class Localizer

The words of a game in several languages: add tables (or addPo / addCsv files), setLanguage, then t, tn (with a count), tc and tcn (in a context). Falls back from pt-BR to pt to the default language, reports missing words, and can pseudo-localise.

Localizer.constructor#

constructor({ language = '', fallback = '', pseudo = false, missing = 'key', onMissing = null } = {})
NameTypeDescription
o (optional)LocalizerOptions
o.language (optional)stringThe language to show ('' until setLanguage).
o.fallback (optional)stringThe language to use for words the chosen one lacks (the first one added).
o.pseudo (optional)booleanShow every string as pseudo-text.
o.missing (optional)'key' | 'brackets'What a word that is nowhere shows: the key itself (default, like gettext) or [key].
o.onMissing (optional)FunctionCalled once for each word that could not be found (language, key, context): log it or collect it.

setPlural(language, rule, count = 0)

Say how many forms a language has and which one a count uses, as a function or a gettext rule ('nplurals=2; plural=(n != 1);'). Without this the language's built-in rules (CLDR, from Intl.PluralRules) are used.

Add the translations of a gettext .po file (msgctxt, plurals and the Plural-Forms header are understood). Untranslated and fuzzy entries are skipped unless fuzzy: true. The language is the file's Language: header unless you give one. Returns how many words were added.

Localizer.addCsv#

addCsv(source, { delimiter = ',' } = {})

Add translations from a spreadsheet saved as CSV. The first row names the columns: key, an optional context, then one column per language code. Rows named thing.one / thing.other are the forms of one word. Empty cells are left untranslated. Returns the language codes found.

testkit

@engine/testkit

Test a game in a real browser from a script: drive headless Chrome, time frames, check the built pages; never leaves a browser running.

npm install @engine/testkit

Version 0.1.0. The package's own README (packages/testkit) explains how the pieces fit together; this page lists every export.

CPU_RENDER_ARGS#

const CPU_RENDER_ARGS

Chrome flags that draw on the CPU (a software graphics card). It is far slower than any real card and balances work differently (it has no early depth test, for one), so it cannot say how fast a game runs on a given card; it does show what scales with the picture (pixels, passes), and by how much, on a machine with no slow card to hand.

Value: Object.freeze(['--use-angle=swiftshader', '--use-gl=angle'])

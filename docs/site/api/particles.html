@engine/particles

Particle effects for the 3D renderer: data-driven bursts and emitters, streaks, decals, additive glow; presets for muzzle flashes, impacts, bullet holes, dust, explosions.

npm install @engine/particles

Version 0.1.0. The package's own README (packages/particles) explains how the pieces fit together; this page lists every export.

class ParticleSystem#

class ParticleSystem

Simulates particles on the CPU into a fixed-capacity pool: burst and line make effects at once, emitter makes continuous ones, update(dt) moves everything (gravity, an optional bouncing floor), and writeTo(batch) fills a ParticleBatch for the renderer. Seeded, so the same calls give the same particles.

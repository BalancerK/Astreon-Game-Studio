@engine/editor

Browser scene editor: viewport with gizmos, hierarchy, inspector generated from prefabs, undo, saving, Play-in-editor; the pieces also work without a page.

npm install @engine/editor

Version 0.1.0. The package's own README (packages/editor) explains how the pieces fit together; this page lists every export.

snapAngle#

function snapAngle(axis, start, angle, targets, { threshold })

Snap the angle of a turn about an axis so that the turned thing's sides run parallel to the sides of something else (the world's axes, another object, the 3D cursor). For each side of the thing and each side of a target it works out the angle that makes them parallel (in the plane the turn happens in; a side that points along the axis does not turn and is left out), and takes the one nearest the angle asked for if it is within reach. Sides count in both directions, so a box also meets a target a quarter turn away.

Parameters

NameTypeDescription
axisnumber[]the unit axis of the turn (world)
startnumber[]the thing's orientation before the turn, a quaternion [x, y, z, w]
anglenumberthe turn asked for, radians
targetsnumber[][]orientations to line up with (quaternions)
o{threshold: number}how close (radians) before it jumps

Returns {angle: number, target: number, from: number[], to: number[]} \| null — the snapped angle, which target it met (an index into targets), and the directions of the thing's side and the target's side (after the turn) that are now parallel; null when nothing is in reach

snapStretch#

function snapStretch(factor, axes, targets, self, { threshold, near = 3, floor = true })

Snap the size of a box that is being stretched about its middle. Each side of the box moves out (or in) by the same amount, so the question is how far from the middle a side may be: it snaps to a place where it meets a side or the middle of another box, to the floor and the world's other planes (zero), or to the other box's own half size (the same width, height or depth).

Parameters

NameTypeDescription
factornumberthe stretch asked for (1 leaves the box as it is); the same on every axis that is stretching
axes{half: number, centre: number, k: number | null}[]the axes that stretch: the half size now, where the middle is along the world axis k (null when the box's axis does not run along a world axis: nothing can snap on it)
targets{min: number[], max: number[], id?: string}[]the other boxes
self{min: number[], max: number[]}the box that holds the stretching one now (to say which others are near)
o{threshold: number, near?: number, floor?: boolean}threshold: how close (world units) before it jumps; near: how far away on the other axes a box may be and still count

Returns {factor: number, kind: 'side' \| 'size', axis: number, k: number, value: number, target: object \| null} \| null — the snapped stretch, or null when nothing is in reach

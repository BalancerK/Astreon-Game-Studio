@engine/hud

HUD widgets for a 2D canvas over a 3D view: panels, gauges, cooldown sweeps, a compass tape, a turning radar, off-screen arrows and a frame-time overlay.

npm install @engine/hud

Version 0.1.0. The package's own README (packages/hud) explains how the pieces fit together; this page lists every export.

screenDirection#

function screenDirection(eye, target, yaw, pitch)

Which way, on the screen, a place is from the crosshair: the angle of the arrow that points to it (0 is to the right, a quarter turn is down), and how far in front of the view it is (1 straight ahead, -1 straight behind). It is worked out in the camera's own directions (right, up, forward), so it is true whatever the camera's pitch: looking up at the sky, a place below and in front points down, and one behind you points up (the shortest way to face it is over the top), each to the side it really is on. The camera's convention is the one of this engine's renderer: yaw 0 looks along -z, and a positive pitch looks up.

Parameters

NameTypeDescription
eyenumber[]where the view is from
targetnumber[]the place
yawnumberthe camera's yaw
pitchnumberthe camera's pitch (up is positive)

Returns {angle: number, front: number, off: number} \| null — off is how far from the middle of the view it is, in radians; null if it is on top of the eye

@engine/match

A match layer: score, assists, streaks, respawns, win rules, control points and a results summary, from a game's events.

npm install @engine/match

Version 0.1.0. The package's own README (packages/match) explains how the pieces fit together; this page lists every export.

controlPoints#

function controlPoints(map, a, b)

The control points of a map: one in the middle between where the two teams start and one far out on each flank, on open land, each as near as can be to equally far from both teams, so that neither starts with a point to itself. A point is found by looking over the land round where it ought to be for a place that is mostly above the sea all the way round and not steep (on a map without land to look at, the spawn points stand in). Pure: the same map and starts give the same points.

Parameters

NameTypeDescription
map{spawns: number[][], heightAt?: (x: number, z: number) => number, half?: number}
a (optional)number[]where the first team starts (x, z; the first spawn point if left out)
b (optional)number[]where the second does (the spawn furthest from the first)

Returns Array<{x: number, z: number, r: number, control: number, owner: number, name: string}>

function stepMatch(match, events)

Take in what happened this tick: score the kills, queue the comebacks, bring back actors whose time is up, and decide whether the match is over. The events: shot (owner, pellet for the extra pellets of one shot), hit (attacker, target, dealt, part, weapon), destroyed (target, by), capture (point, team, name, made by the control points), and anything the rules' onEvent takes.

MatchRules#

What the match needs to know about the game it is scoring (every one is optional).

Type: object

NameTypeDescription
actors (optional)(world: any) => any[]Everything that can score: { id, team, dead, x, z, name } each (default world.actors).
spawns (optional)(world: any) => number[][]Places to come back at, [x, z] each (default world.spawns).
respawn (optional)(world: any, actor: any, at: number[]) => voidBring a destroyed actor back at at (default: nothing).
maxHealth (optional)(actor: any) => numberHow much damage an actor can take at most, for the assists (default 100).
isMelee (optional)(weapon: string) => booleanWhether a kill with this weapon is a close-quarters one (default none).
label (optional)(actor: any) => stringA short word about an actor for the results screen (default empty).
points (optional)Record<string, number>The points for each kind of award (default POINTS; spread it to add the game's own kinds).
partOf (optional)Record<string, string>Which part of the score each kind of award belongs to (default PART_OF).
onEvent (optional)(match: any, event: any, tools: {award: Function, scoreOf: Function}) => booleanCalled first for every event; return true if it was the game's own kind of event (a parry), which the match then leaves alone.
actorKind (optional)stringWhat the winner or leader is called when it is one actor and not a team (winner.kind; default 'actor').
ticksPerSecond (optional)numberHow many simulation ticks make a second (default 60).

@engine/skeleton2d

2D skeletal animation: bones, skins, weighted meshes with deformation, IK, keyframes with curves and events, crossfading tracks, drawn through the renderer's mesh batch.

npm install @engine/skeleton2d

Version 0.1.0. The package's own README (packages/skeleton2d) explains how the pieces fit together; this page lists every export.

drawSkeleton#

function drawSkeleton(skeleton, meshes, atlas, { tint = [1, 1, 1, 1] } = {})

Put what a skeleton shows into a mesh batch, back to front, ready for renderer.render({ camera, batch, meshes }). Regions become two triangles, meshes keep their own triangles, bounding boxes are skipped. The colour of a point is the skeleton's colour times the slot's times the attachment's times tint; slots set to additive add their light instead of covering.

o (optional){tint?: number[]}tint: an extra [r, g, b, a] in 0..1.

Returns number — How many triangles were added.

class Skeleton#

class Skeleton

The runtime copy of a skeleton: poses, slot colours and shown attachments, constraints. Animations change its bones' and slots' fields; updateWorldTransform() then works out where everything is.

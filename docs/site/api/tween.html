@engine/tween

Tweens and timelines: 30+ easings, delays, repeats, yoyo, relative values, labels, overlapping steps, seeking; deterministic.

npm install @engine/tween

Version 0.1.0. The package's own README (packages/tween) explains how the pieces fit together; this page lists every export.

class Timeline#

class Timeline extends Animation

Several tweens, calls and other timelines laid out on one clock, played, repeated, sped up, paused and sought as one. Items go at the end by default, or at a time (2), after a label ('boom+=0.5'), relative to the end ('-=0.3', overlapping), or with the previous item ('<', '<+=0.2').

class Tween#

class Tween extends Animation

Moves properties of target to new values. Make them with Tweens.to(...) (which also plays them), or directly and call update(dt) yourself. Properties may be dotted paths ('position.x'), numbers, lists of numbers ([r, g, b] are tweened in place, also typed arrays), and relative ('+=50').

class Tweens#

class Tweens

Plays tweens and timelines: make them with to, from, fromTo or timeline, then call update(dt) once per step. Finished and killed ones are dropped.

const tweens = new Tweens();
tweens.to(box, { x: 300, 'scale.y': 2 }, { duration: 1, ease: 'elasticOut', onComplete: () => spawnDust() });
tweens.timeline().to(a, { y: 0 }, { duration: 0.3 }).call(playSound).to(b, { alpha: 1 }, { duration: 0.2 }, '-=0.1');
// each step:  tweens.update(1 / 60);

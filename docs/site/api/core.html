class FixedLoop#

class FixedLoop

Fixed-timestep simulation loop. Runs identically on client and server: the host feeds it elapsed time, it calls update at a constant rate and render with an interpolation alpha. No timers or DOM inside, so it is trivially testable and deterministic.

FixedLoop.constructor#

class Scheduler#

class Scheduler

Orders systems by before/after constraints (stable: ties keep registration order). Constraints naming systems that are not registered are ignored, so a plugin can say "before render" and still work on a headless server.

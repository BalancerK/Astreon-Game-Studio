@engine/scene

Levels as data (scene files, validation, migrations, loading and unloading) and the undoable SceneDocument the editor uses.

npm install @engine/scene

Version 0.1.0. The package's own README (packages/scene) explains how the pieces fit together; this page lists every export.

loadScene#

async function loadScene(data, spawner, { assets, offset, onProgress, validate = true, filter } = {})

Load a scene's assets, then spawn its entities. Parents are spawned before their children; a child's at is relative to its parent.

Parameters

NameTypeDescription
dataanyThe scene file (parsed JSON; older versions are upgraded).
spawnerimport('../../prefab/src/spawner.js').PrefabSpawner
o (optional)object
o.assets (optional)import('../../assets/src/manager.js').AssetManagerLoads the scene's assets first (and holds them until the scene is unloaded).
o.offset (optional){x?: number, y?: number, z?: number}Move the whole scene (streaming levels side by side). Only applies to entities without a parent.
o.onProgress (optional)(p: {loaded: number, total: number, path: string}) => void
o.validate (optional)booleanCheck the scene against the prefab library first (default true): every problem is reported together, before anything spawns.
o.filter (optional)(entity: any) => booleanSkip entities (and their children) for which this returns false.

Returns Promise<LoadedScene>

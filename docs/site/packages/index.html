Packages

The engine is 26 small packages. Each is optional, has a README, and may only import the packages listed on its page. Use the ones your game needs; Start here says which.

The wire format: binary reader/writer, quantizing codecs, replicated-state schema, delta snapshots with acks, handshake and input messages.

The Transport / Listener contract, the in-memory network, and the network condition simulator.

Server-side replication: who gets told what, and how much. Game-agnostic; the arena example shows it in use.

# @engine/i18n

Localisation: plural forms for every language, contexts, gettext .po and CSV import, fallback chains (pt-BR to pt), pseudo-localisation, a list of what is untranslated.

```
npm install @engine/i18n
```

Version 0.1.0. The package's own README ([packages/i18n](../../packages/i18n/README.md)) explains how the pieces fit together; this page lists every export.

## Classes

### `class Localizer`

```js
class Localizer
```

The words of a game in several languages: `add` tables (or `addPo` / `addCsv` files), `setLanguage`, then `t`, `tn` (with a count), `tc` and `tcn` (in a context).
Falls back from `pt-BR` to `pt` to the default language, reports missing words, and can pseudo-localise.

#### `Localizer.constructor`

```js
constructor({ language = '', fallback = '', pseudo = false, missing = 'key', onMissing = null } = {})
```

| Name | Type | Description |
|---|---|---|
| `o` (optional) | `LocalizerOptions` |  |
| `o.language` (optional) | `string` | The language to show ('' until `setLanguage`). |
| `o.fallback` (optional) | `string` | The language to use for words the chosen one lacks (the first one added). |
| `o.pseudo` (optional) | `boolean` | Show every string as pseudo-text. |
| `o.missing` (optional) | `'key' \| 'brackets'` | What a word that is nowhere shows: the key itself (default, like gettext) or `[key]`. |
| `o.onMissing` (optional) | `Function` | Called once for each word that could not be found (language, key, context): log it or collect it. |

## Types

### `Entry`

What a word can be in a table: plain text, a list of forms in the language's plural order (what gettext files give), or the forms by name.

Type: `string \| string[] \| Partial<Record<'zero' \| 'one' \| 'two' \| 'few' \| 'many' \| 'other', string>>`

### `LocalizerOptions`

Type: `{ language?: string, fallback?: string, pseudo?: boolean, missing?: 'key' \| 'brackets', onMissing?: (language: string, key: string, context: string \| null) => void }`

### `PoEntry`

Type: `{ context: string \| null, id: string, plural: string \| null, forms: string[], fuzzy: boolean, comments: string[] }`

### `PoFile`

Type: `{ header: Record<string, string>, entries: PoEntry[] }`
